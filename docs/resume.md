## 1. Текущее состояние

`web-gui` — работающий браузерный редактор исходных данных Clark. Текущая
версия приложения в рабочей ветке — **4.27.0**, базовый `main` при реорганизации документации:
`105d7789c63ef9e012dbb4328b812de7535c72d3`.

Реализованы выбор и редактирование задания, валидация и безопасное сохранение,
локальные и базовые библиотеки материалов, импорт legacy-данных, графики и
генераторы, 3D-представление геометрии и источников, деморежим, установка
примеров, сводки исходных данных и результатов, а также формирование списка и
запрос запуска локального Clark.

Подробное текущее поведение описано в:

- [контрактах данных](AI_DATA_CONTRACTS.md);
- [контрактах интерфейса](AI_UI_CONTRACTS.md);
- [контракте интеграции с Clark](AI_CLARK_INTEGRATION.md);
- [справочнике по сборке и выполнению](AI_BUILD_AND_RUNTIME.md).

## 2. Текущие проблемы

Подробные карточки находятся в
[`AI_ARCHITECTURE_AUDIT.md`](AI_ARCHITECTURE_AUDIT.md). Существенные открытые
темы:

- несогласованное ожидание единиц в одном тесте `elementsValidator`
  ([WGUI-001](AI_ARCHITECTURE_AUDIT.md#wgui-001--единицы-ориентированного-объёма));
- не реализовано межвкладочное правило `MC-ELEMENTS-001`
  ([WGUI-002](AI_ARCHITECTURE_AUDIT.md#wgui-002--модельное-ограничение-mc-elements-001));
- реальный запуск через `clark://`, поздние 3D-сценарии и ряд браузерных
  операций требуют актуального подтверждения
  ([WGUI-006–WGUI-009](AI_ARCHITECTURE_AUDIT.md#сводка)).

Первый незавершённый ранее согласованный приоритет — реализация
`MC-ELEMENTS-001`. Порядок и зависимости находятся в
[`AI_ROADMAP.md`](AI_ROADMAP.md).

Добавлена поддержка готового `jweak_local.json`: проверка родительских контактов
без преобразования MED и `dp`; структурные операции KV временно запрещены.
[Контракт](AI_DATA_CONTRACTS.md#jweak-local-input). Остаётся нативная файловая
приёмка [WGUI-012](AI_ARCHITECTURE_AUDIT.md#wgui-012).

## 3. Проверка

В проекте 75 файлов Node.js-тестов и отдельные сборки Vite для release и GitHub
Pages. Исторический полный прогон на прежнем commit имел 426 успешных проверок и
один сбой WGUI-001; этот результат не объявляется состоянием текущего `main`.

Точные команды, ручные сценарии и границы подтверждений находятся в
[`AI_VERIFICATION.md`](AI_VERIFICATION.md).
