# Clark UI Editor

Обновлено: 2026-09-15 00:20 UTC+3.

Текущая версия: **4.20.3**.

Clark UI Editor — браузерный редактор исходных данных заданий Clark. Он
позволяет выбрать проект и задание, проверить и изменить данные `input3XX`,
просмотреть геометрию и характеристики, сохранить модель и подготовить список
для запуска локального решателя.

Опубликованное приложение:
[y26084670-blip.github.io/web-gui](https://y26084670-blip.github.io/web-gui/).

## Требования

Для полной работы с локальными файлами рекомендуются актуальные Google Chrome
Desktop или Microsoft Edge Desktop. Нужны:

- HTTPS либо `localhost`;
- поддержка File System Access API;
- разрешение пользователя на чтение и запись выбранного каталога.

Приложение заранее проверяет безопасный контекст и нужные методы API. Отдельный
Chromium SDK устанавливать не требуется.

Для разработки и сборки используется Node.js 24. Точное дерево зависимостей
зафиксировано в [`package-lock.json`](package-lock.json).

## Быстрое знакомство

Кнопка «Демо» загружает встроенное задание без выбора каталога. Таблицы,
графики, диагностика и 3D работают с копией в памяти браузера. Сохранение на
диск отключено; повторная загрузка демо восстанавливает исходные данные.

Кнопка `?` открывает «Общую информацию» с краткой последовательностью работы,
установкой примеров и решателя и используемыми единицами.

## Работа с локальным заданием

1. На вкладке «Выбор задания» нажмите «Выбрать каталог с проектами».
2. Выберите обычный каталог `clark.projects` либо другой базовый каталог с
   проектами.
3. Выберите проект и задание, проверьте предпросмотр и нажмите «Загрузить для
   редактирования».
4. Изменяйте данные на предметных вкладках; общая проверка показывает ошибки и
   предупреждения.
5. Нажмите «Сохранить модель».

Перед записью редактор создаёт `input3XX/_nogo.e3d`. Маркер удаляется только
после полной записи и свежей проверки без ошибок. Его наличие предупреждает
решатель о неподтверждённых исходных данных, но само по себе не блокирует
расчёт.

Правая панель выбора задания показывает текст
`output3XX/_summary_out.txt`. Повторный щелчок по заданию перечитывает файл.
Средняя панель показывает `input3XX/_summary.txt`.

## Примеры и решатель

В «Общей информации»:

- «Установить примеры» копирует опубликованное дерево заданий в выбранный
  локальный каталог, пропуская уже существующие файлы;
- «Скачать установщик решателя» открывает
  [облачный каталог](https://cloud.mail.ru/public/nLj8/CVS8JAToQ), где
  пользователь выбирает актуальный установочный файл.

После установки Clark в папке `Clark` на рабочем столе находятся ярлыки
приложений. Подробная инструкция поставки принадлежит
[проекту solver](https://github.com/y26084670-blip/solver/blob/main/README.md).
Публикация новой версии сайта не обновляет установленный Clark.

## Список заданий и запуск Clark

Кнопка «Формирование списка заданий и запуск решателей или импорта» открывает
плавающее окно управления `clark.tasks.txt` в корне базового каталога.

Обычная последовательность:

1. «Обновить список».
2. Выделить строки и выбрать «Подключить» или «Отключить».
3. Перед первым запуском нажать «Связать с Clark», подтвердить открытие
   обработчика и выбрать тот же базовый каталог.
4. Выбрать запуск расчёта, клиента электрической цепи или импорта.

Начальный `*` означает отключённое задание. Пути относительны базовому каталогу,
поэтому дерево можно переносить вместе со списком. Запуск относится ко всем
подключённым строкам, а не только к выделенному или загруженному заданию.
Клиент электрической цепи требует одно задание REAL64; импорт может
перезаписывать JSON. Для демо запуск недоступен.

Точный контракт находится в
[`docs/AI_CLARK_INTEGRATION.md`](docs/AI_CLARK_INTEGRATION.md).

## Рабочие константы

Актуальный `conrab.txt` содержит отдельные строки Float32 и Float64. Если в
старом файле одна строка, редактор загружает её в обе колонки и помечает
вкладку как требующую сохранения.

`StartITER` сохраняется как логическое поле `startITER`:

- `true` — нулевое начальное приближение;
- `false` — значения предыдущей итерации.

Значения двух профилей независимы. Для расчёта требуется версия solver,
поддерживающая это поле.

## 3D и графики

3D-окно и предпросмотр показывают геометрию, дискретизацию, симметричные образы,
движение и заданные источники в выбранный момент. «Полный вид» вписывает
видимые объекты по текущей проекции. Клавиши A/X/Y/Z выбирают осевые виды,
Ctrl+X/Y/Z — противоположные.

Опция «Заданные источники» показывает зелёные векторы намагниченности и красные
векторы плотности тока. Кнопка ⚙ выбирает тонкие или объёмные стрелки и их
видимый масштаб. Настройки отображения и выбранный момент не изменяют исходные
данные.

Подробное поведение интерфейса описано в
[`docs/AI_UI_CONTRACTS.md`](docs/AI_UI_CONTRACTS.md).

## Разработка

Установка зависимостей строго по lock-файлу:

```bat
npm ci
```

Dev server:

```bat
npm run dev
```

На Windows доступен сценарий:

```bat
scripts\dev.cmd
```

Production-сборка:

```bat
npm run build:release
```

Сборка для GitHub Pages:

```bat
npm run build:pages
```

Локальный просмотр `dist`:

```bat
npm run preview
```

Тесты Node.js:

```bat
npm test
```

Полные режимы, Caddy, ресурсы, публикация и диагностика находятся в
[`docs/AI_BUILD_AND_RUNTIME.md`](docs/AI_BUILD_AND_RUNTIME.md). Критерии и
границы проверок — в
[`docs/AI_VERIFICATION.md`](docs/AI_VERIFICATION.md).
