*** пояснение к эл цепи ***

>>> Подробное описание модели и утилит:
	\CLARK.MPI.START.204\addons\Circuit\модель_многофазной_цепи.docx

>>> Общее описание:
Эл цепm состоит из N ветвей (фаз), соединенных параллельно в общих концах ветви: точках A, B. 
Каждая ветвь с номером  состоит из заданной ЭДС и последовательно включенной группы M параллельно включенных между 
собой доп ветвей. В группе каждая доп ветвь содержит последовательно включенные элементы:
- индуктивный элемент с нелинейной зависимостью потокосцепления от токов во всех ветвях цепи;
- нелинейное активное сопротивление, обусловленное неидеальностью сверхпроводящего состояния ВТСП катушкиж;
- постоянную собственную индуктивность дополнительной ветви;
- постоянное активное сопротивление дополнительной ветви.
Точки A, B могут быть дополнительно соединены (закорочены) проводом (схема с "нулевым" проводом).
В противном случае имеем схему без "нулевого" провода.

>>> Порядок задания исходных данных в этом файле (подряд идущие значения разделяются пробелом и/или табуляцией):
(а) Строка значений N M, где N-число основных ветвей, M-число подветвей в группе.
(б) Далее N групп строк, соответствующих каждой фазе. Число строк в каждой группе равно M+1, причем:
строка 1 в группе: 
	-имя файла в каталоге задачи с временными узлами аппроксимации нормированного напряжения как функции времени 
	(если файл не найден, то - используются нулевые значения ЭДС в данной фазе)
строки 2,...M+1: каждая из строк содержит значения для подветки как последовательности следующих элементов:
	-номер искомого импульса, описывающего ток в цепи (изначально нулеввые токи для каждого момента времени)
	-номер измерительной катушки в эл цепи (или 0, если нет катушки)
	-значение постоянной индуктивности, Гн
	-значение постоянного активного сопротивления, Ом
(в) Далее расположены строки одиночных значений общих параметров с соответствующими комментариями.
